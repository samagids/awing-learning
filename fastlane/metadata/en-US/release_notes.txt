What's new in 1.19.3:

• New Awing keyboard: when you type in a text field that needs Awing
  (Contribute, Translate, Report a wrong translation), the app now
  shows an in-app keyboard with all the Awing letters (ɛ ɔ ə ɨ ŋ),
  the curly glottal stop, and tone marks (á à â ǎ). No more fighting
  with the English keyboard.

• Better offline AI feedback: the download and generation flow now
  reports the actual reason when something goes wrong (previously it
  showed "Cloud AI did not return..." even when you had Cloud OFF).
  Delete + re-download the model in Settings actually clears the
  file from disk now.

• Full-screen support for Android 15+ (edge-to-edge display).

• Assorted bug fixes and voice tuning.

Built with love for the Awing community.
