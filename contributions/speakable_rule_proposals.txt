HOW TO APPLY (manual)
----------------------------------------------------------------------
1. Review the PROPOSED RULE CHANGES table above. A high-impact
   row (e.g. 'ə' → 'a' with 2000 unrecorded_affected) means
   updating one line of scripts/generate_audio_edge.py would
   change ~2000 unrecorded words' Edge TTS output.

2. Edit scripts/generate_audio_edge.py awing_to_speakable() to
   incorporate the high-impact rules.

3. Regenerate ONLY unrecorded words:
   python scripts/generate_audio_edge.py generate
   (the regenerate command's existing behaviour: native-recorded
   words are skipped because the runtime fallback already plays
   the native clip — Edge TTS output for those words is unused)

4. No file in the app code is modified by this script. Recorded
   words remain untouched.
